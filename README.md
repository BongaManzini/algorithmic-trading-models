# 📈 Algorithmic Trading & Financial Modeling

Quantitative financial analysis scripts and technical indicators dashboard using `yfinance`, `pandas`, and `matplotlib`.

---

## ✨ Features

- **Automated Historical Market Data Pipeline**: Fetches end-of-day pricing data directly from Yahoo Finance.
- **Technical Indicators**: Calculates 14-day Relative Strength Index (RSI), 50-day Simple Moving Average (SMA50), and 200-day Simple Moving Average (SMA200).
- **Dual-Pane Visualization**: High-resolution synchronized time-series plots for price trends, golden crosses, and momentum overbought/oversold boundaries.

---

## 🚀 Usage

```bash
# Install dependencies
pip install yfinance pandas matplotlib

# Run technical indicator model
python AlgoTrad-FinanModeling/AlgoTrad01.py
```
